# TailTap 临时连接与链路诊断 PRD

日期：2026-10-04

## 1. 目标与范围

TailTap 用临时连接卡分享 TCP 服务，接收方通过连接卡建立反向端口映射。用户可以收藏常用配置，并查看任务状态与当前链路诊断。

本文描述当前产品行为。分享任务每次启动生成临时连接卡，停止任务或到期后连接卡失效。收藏只保存可复用的服务配置，不保存可长期使用的连接凭据。

首轮覆盖桌面端和 Android 的 TCP、SSH、网页服务。文件传输尚未实现，另见[文件分享 PRD](file-sharing-prd.md)。

## 2. 核心交互

### 2.1 分享与连接服务

首页保留“分享服务”和“连接服务”两个主要入口。两个表单使用一致的层级与字段样式，服务用途以水平分段控件展示，常用配置直接可见；高级字段按服务类型展示，不藏在额外的“更多选项”操作里。

分享表单配置本机可访问的目标地址、目标端口、自动停止时间及可选名称。接收连接卡时，可配置本机监听端口、服务用途、SSH 用户名及网页协议和路径。桌面端可预填当前系统用户名，Android 留空；接收方可以修改用户名。

表单里的提示和安全警告使用统一 Notice 样式，放在相关字段或操作旁，不用页尾脚注。连接卡名称、服务用途等由发送方提供，只作识别提示，不代表已验证对方身份。

任务详情顶部状态卡展示服务名称、方向清楚的端口映射、运行状态、运行时长、连接数和流量。连接任务按“远端端口 → 本机监听地址”描述映射。主要操作靠右排列；连接任务的“停止”操作靠左。

### 2.2 临时分享连接卡

分享详情中的主操作打开连接卡面板。面板使用二维码和操作并列的宽布局，以及二维码在上、操作竖排的窄布局。二维码保持清晰的固定边长范围，不随文案高度变化；标题和操作层级一致。

分享操作包括系统分享、复制原始地址、复制 Tailcat 命令和复制连接卡。复制连接卡是主要操作。警告放在正文中，说明连接卡包含访问凭据、只应发送给可信的人、停止分享后卡片失效。

### 2.3 收藏

用户可在任务详情收藏常用服务配置，随后从首页收藏区快速重新打开表单。收藏不保留正在运行的端口映射，不复用过期连接卡，也不代表设备授权。

## 3. 连接诊断

诊断用于呈现核心实际观察到的路径和测量结果，不推断或伪造状态。诊断卡片在任务详情中始终展开显示，不提供折叠开关。

| 信息 | 展示规则 |
|---|---|
| 开始时间 | 显示任务开始时间 |
| 连接路径 | 有实际结果时显示直连或中继；尚无数据时隐藏该行 |
| 最近延迟 | 有测量结果时显示延迟和测量时间；无结果时隐藏 |
| 目标服务 | 仅在执行过实际目标检查后显示可用或不可用；未检查时不显示占位状态 |
| 事件记录 | 展示最近的状态、隧道和路径变化，并按时间更新 |

卡片右上角提供一个重新检查图标和一个复制诊断图标。重新检查触发当前支持的路径检查，操作期间显示进度，完成后更新路径、延迟与事件记录；失败时展示错误原因和时间。不得保留与页面数据不同步的静态“检查完成”提示。

诊断数据来自 Tailcat 核心的真实路径更新与延迟测量。直连和中继是运行时路径状态；重新检查不承诺切换路径。核心未提供的信息应省略，不能用“目标尚未检查”等常驻占位文字填充卡片。

## 4. 生命周期与隐私

每次启动分享任务创建新的临时入口。手动停止、自动到期或进程结束后，入口不再可用。关闭页面不自动停止仍在运行的任务，具体后台行为遵循系统平台规则。

最近任务和诊断记录服务类型、端口、运行时长、流量、路径结果、延迟及错误类别。复制诊断不包含连接卡、原始地址中的凭据或 SSH 私钥。SSH 用户名只用于生成接收端的连接命令，不作为身份验证凭据。

## 5. 非目标

当前版本不提供长期固定入口、持久设备身份、设备授权列表或基于设备身份的访问控制。Tailcat 的临时连接卡是连接访问能力本身，分享方应通过可信渠道交给预期接收者。应用不声称服务名称或连接卡证明了发送方身份。

文件和文件夹传输、内置文件管理器、在线审批、云端账户、永久后台服务均不属于本文范围。

## 6. 验收标准

1. 分享和连接表单用一致的分组、控件层级和警告样式，服务用途可直接水平选择。
2. 分享连接卡在宽窄布局下均保持二维码清晰稳定，正文警告和主要复制操作易于识别。
3. SSH 连接卡可携带可选用户名，接收端命令包含该用户名；未提供用户名时兼容原有命令格式。
4. 连接任务映射按“远端端口 → 本机监听地址”展示。
5. 诊断卡片始终展开。没有检查数据时隐藏相应字段；重新检查后显示最新的真实结果和时间。
6. 路径检查失败、超时和未知值不会显示为成功，且事件记录随检查结果更新。
7. 停止或到期后临时连接卡失效；收藏配置可重新打开表单，但不恢复旧连接卡。
8. 诊断导出不包含访问凭据或 SSH 私钥。
